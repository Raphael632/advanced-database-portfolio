Portfolio 1 is implemented: 3,528 reconciled source observations and 20 passing tests. [Portfolio 2](Ezenduka_Chukwubuikem_301913360_Portfolio2/Ezenduka_Chukwubuikem_301913360_Performance_Analysis.md) has eight analytical queries, measured optimisation evidence and twelve passing tests. [Portfolio 3](Ezenduka_Chukwubuikem_301913360_Portfolio3/Ezenduka_Chukwubuikem_301913360_Transaction_Analysis.md) has nine verified transaction/concurrency scenarios. [Portfolio 4](Ezenduka_Chukwubuikem_301913360_Portfolio4/Ezenduka_Chukwubuikem_301913360_NoSQL_Analysis.md) implements 516 TinyDB documents, six verified queries, review CRUD and twelve passing tests. Visual evidence viewers accompany Portfolios 3 and 4. Student review is pending. Portfolio 5 is not started.

Raw NBS downloads and the populated database remain local under the documented source-use restrictions. This repository includes reproducible code and aggregate evidence.
