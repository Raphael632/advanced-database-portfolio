Model structure

Portfolio 1 relational data (read-only)
       ↓ group by month + exact item label
TinyDB monthly_items
  ├─ identity: document_key, schema_version
  ├─ period + item label
  ├─ publication provenance
  └─ observations[]: geography, level, integer kobo, source cell

TinyDB demo_reviews → document_key reference
  └─ fictional note, status, optional checklist
