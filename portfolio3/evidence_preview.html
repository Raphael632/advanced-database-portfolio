How the version guard protects a review

A and B load task version 0
       ↓
A saves WHERE version = 0 → one row saved → version 1
       ↓
B saves WHERE version = 0 → zero rows saved → conflict
       ↓
B refreshes → reconciles notes → saves WHERE version = 1 → version 2
