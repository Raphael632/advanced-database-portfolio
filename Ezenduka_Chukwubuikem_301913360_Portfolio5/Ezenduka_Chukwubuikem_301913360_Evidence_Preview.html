Portfolio 5: replication, recovery and sharding

Local controlled exercise, not a cloud deployment.

Implemented data flow

Original source (unchanged)
  → Primary copy + atomic review event log
      → Explicit replication worker → Replica + applied sequence
      → Backup at sequence 3 → restored copy
  → Month-range projection → Jan–Jun shard + Jul–Dec shard
